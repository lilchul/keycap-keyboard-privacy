Keymew 개인정보처리방침

시행일 2026년 11월 6일

Keymew는 글자 조합과 커서 이동을 기기에서 처리합니다. 키보드로 입력한 문장이나 클립보드 내용은 Keymew의 서버 또는 분석 서비스로 보내지 않습니다.

키보드와 기기에 저장되는 정보

다른 앱에서 Keymew로 입력할 때 키보드는 글자를 조합하거나 커서를 옮기기 위해 입력 위치 주변의 글자를 읽을 수 있습니다. 사용자가 직접 저장한 문구·이모티콘·저장함 항목과 키보드 설정은 기기에 보관합니다. 저장한 항목은 앱에서 직접 삭제할 수 있습니다.

선택할 수 있는 앱 사용 분석

앱 사용 분석은 기본적으로 꺼져 있습니다. 동의하면 Keymew 본체 앱에서 Google Analytics for Firebase를 시작합니다. 키보드 확장에는 분석 SDK가 없습니다. 동의를 거절해도 테마와 키보드를 이용할 수 있습니다.

  • 테마와 기능 개선. 어떤 테마를 미리 보고 적용했는지, 어떤 분류와 화면을 열었는지, 소리 미리듣기가 어느 단계에서 실패했는지 등을 Google에 전송합니다. 검색어와 저장 문구의 내용은 이벤트에 포함하지 않습니다.
  • 이용 환경 파악. Google은 앱 설치별 식별자, 앱과 운영체제 버전, 기기 정보, 세션 정보, 네트워크 접속에서 추정한 대략적인 지역을 처리합니다. 같은 설치에서 발생한 이벤트를 서로 연결할 수 있습니다. 정밀 위치나 광고 식별자(IDFA)는 수집하지 않으며, 이 데이터를 광고나 다른 회사의 앱·웹사이트에 걸친 추적에 사용하지 않습니다.
  • 보관 기간. Google Analytics의 사용자별·이벤트별 데이터 보관 기간은 2개월이며 새 활동이 있어도 기간을 연장하지 않도록 설정했습니다. 이 기간은 전체 이용 횟수와 같은 집계 보고서에는 적용되지 않습니다. Google의 보관 기간 안내

동의를 철회하려면 Keymew 앱의 설정에서 ‘앱 사용 분석 공유’를 끄세요. 이후 분석 수집을 중단하고 기기에 있는 분석 상태를 초기화합니다. 이미 전송한 데이터의 삭제를 원하시면 아래 연락처로 요청할 수 있습니다.

테마·사전·미리보기 다운로드

무료 테마 6개는 앱에 포함됩니다. 추가 테마나 언어 데이터를 받을 때, 또는 갤러리에서 미리보기 이미지가 화면에 나타날 때 앱이 Cloudflare에 해당 파일을 요청합니다. 이 과정에서 요청한 리소스의 경로·식별자와 버전, 접속 IP 주소가 처리됩니다. 키보드 입력 내용이나 구매 영수증은 파일 요청에 포함되지 않습니다.

테마·언어 데이터의 다운로드 요청에는 IP별 요청 횟수 제한을 적용해 서비스 남용을 방지합니다. Keymew는 테마 파일과 미리보기 이미지를 저장한 두 버킷 모두에서 개별 파일 접근 기록(Data Access Logs)을 꺼 두었으며, 요청 로그를 외부로 내보내는 Logpush 작업도 사용하지 않습니다. Cloudflare가 자체 네트워크 운영과 보안을 위해 처리하는 정보에는 Cloudflare 개인정보처리방침이 적용됩니다.

받은 테마와 언어 데이터는 기기에 보관하며 앱 설정의 ‘다운로드 관리’에서 삭제할 수 있습니다. 미리보기 이미지는 다시 내려받는 일을 줄이기 위해 기기에 임시 저장됩니다.

프리미엄 구매와 복원

결제와 구독은 Apple이 처리합니다. Keymew는 구매 복원과 유료 테마 사용 여부를 확인하기 위해 Apple의 거래 정보를 검증하고, 상품 종류·이용 만료일·확인 시각 등을 기기에 저장해 키보드와 공유합니다. Keymew 운영자는 카드 번호나 결제 수단 정보를 받지 않습니다. Apple 개인정보 처리방침

외부 서비스와 국외 처리

Google LLC는 분석에 동의한 후 앱을 사용할 때 위 분석 정보를, Cloudflare, Inc.는 파일을 요청할 때 위 다운로드 정보를 네트워크를 통해 처리합니다. 각 서비스는 미국을 포함해 서버를 운영하는 국가에서 데이터를 처리할 수 있습니다. 분석 전송은 앱 설정에서 끌 수 있습니다. 다운로드 정보는 해당 온라인 파일을 제공하기 위해 처리합니다. Firebase 개인정보 보호 및 보안 · Cloudflare 개인정보처리방침
